## Modified Mirabox Stream Dock Discord plugin

A cleaned up fork of the Discord plugin for Mirabox Stream Dock, modified for [OpenDeck](https://github.com/nekename/OpenDeck) compatibility

#### Actions

- Mute
- Deafen
- Voice Channel
- Text Channel
- Notifications
- User Volume Control
- Volume Control
- Soundboard
- Set Audio Device
- Mute Control
- Deafen Control

#### Changes from upstream

- Formatted, cleaned up and translated codebase
- Improved translations and made English the default language
- Replaced icons with ones that match Discord interfaces
- Improved ergonomics of usage with OpenDeck
- Removed Chinese and Mirabox Stream Dock-specific quirks
- Added support for detecting Flatpak and Snap installations of Discord
- Fixed bugs and made quality of life improvements

View the full [commit timeline](https://github.com/nekename/mirabox-discord-plugin-opendeck/compare/2eaab4fde7cf4cb9cb074e4d80b96a87ac844cdc...main) on GitHub for a detailed description of the changes made.
